# Repositório do Livro "Dominando o Android"

Este repositório contém o código-fonte do livro "Dominando o Android", organizando os projetos de exemplo em diretórios que correspondem aos capítulos e seções do livro.

## Estrutura do Repositório

O repositório está dividido em diretórios, cada um correspondendo a um passo do desenvolvimento do aplicativo "Carros". A estrutura é a seguinte:

- `Passo01-CriarProjeto`: Criação do projeto inicial no Android Studio.
- `Passo02-Toolbar`: Configuração da Toolbar.
- `Passo03-parte1-NavDrawer`: Implementação do Navigation Drawer.
- `Passo03-parte2-NavDrawer-MaterialDesign`: Aplicação do Material Design no Navigation Drawer.
- `Passo04-NavDrawer+Fragments`: Integração do Navigation Drawer com Fragments.
- `Passo05-WebView`: Uso de WebView para exibir páginas da web.
- `Passo06-RecyclerView`: Implementação de listas com RecyclerView.
- `Passo07-RecyclerView-Detalhes`: Exibição de detalhes a partir de um item da lista.
- `Passo08-XML`: Leitura de dados de um arquivo XML.
- `Passo09-JSON`: Leitura de dados de um arquivo JSON.
- `Passo10-WebService`: Consumo de Web Services.
- `Passo11-WebService_Arquivos`: Consumo de Web Services com manipulação de arquivos.
- `Passo12-SharedPreferences`: Uso de SharedPreferences para salvar preferências.
- `Passo13-Configuracoes`: Tela de configurações.
- `Passo14-SQLite`: Uso do banco de dados SQLite.
- `Passo15-Backup`: Implementação de backup dos dados.
- `Passo16-OnLongClick`: Tratamento de eventos de clique longo.
- `Passo17-Share`: Compartilhamento de conteúdo.
- `Passo18-CarroIntent`: Uso de Intents para navegação entre telas.
- `Passo19-Video`: Exibição de vídeos.
- `Passo20-Mapa`: Integração com mapas.
- `Passo21-ContentProvider`: Uso de Content Providers.
- `Passo22-Gradle`: Configurações avançadas do Gradle.
- `Passo23-MaterialPlus`: Aplicação de componentes avançados do Material Design.

## Como Utilizar

Cada diretório `PassoXX` contém um projeto Android completo e funcional que pode ser aberto no Android Studio. Para acompanhar o livro, você pode abrir cada projeto sequencialmente e analisar as alterações em relação ao passo anterior.

Para clonar este repositório, utilize o seguinte comando:

```bash
git clone https://github.com/livroandroid/carros.git
```

## Sobre o Livro

Este livro é um guia completo para o desenvolvimento de aplicativos Android, cobrindo desde o básico até tópicos avançados. O código-fonte neste repositório serve como material de apoio para os exemplos e exercícios propostos no livro.
